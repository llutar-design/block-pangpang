# 블록 팡팡!

8×8 판에 블록을 끌어다 놓아 가로·세로 줄을 터뜨리는 퍼즐 게임입니다.
HTML, CSS, Vanilla JavaScript만 사용하며 서버, 로그인, 외부 라이브러리, 네트워크가 필요 없습니다.

**바로 플레이: https://llutar-design.github.io/block-pangpang/**

## 실행 방법

`index.html`을 더블클릭해 브라우저로 열면 바로 플레이할 수 있습니다. 설치나 빌드는 필요 없습니다.

휴대폰에서 테스트하려면 PC에서 간단한 웹 서버를 띄운 뒤 같은 Wi-Fi에서 접속합니다.

```bash
python -m http.server 8000
# 휴대폰 브라우저에서 http://<PC의 IP 주소>:8000 접속
```

## 배포 방법

정적 파일이므로 아래 세 파일을 웹 호스팅에 올리면 끝입니다. `tests` 폴더는 올리지 않아도 됩니다.

```
index.html
style.css
game.js
```

- **GitHub Pages**: 저장소에 파일을 올리고 Settings → Pages에서 배포할 브랜치를 선택합니다.
- **Netlify**: Netlify Drop 페이지에 폴더를 끌어다 놓습니다.
- **그 밖의 호스팅**: 웹 루트에 세 파일을 복사합니다. 서버 설정은 필요 없습니다.

## 게임 규칙

- 아래에 주어지는 서로 다른 블록 3개를 판의 빈 곳에 놓습니다. 회전은 할 수 없습니다.
- 가로 또는 세로 8칸을 채우면 줄이 사라집니다. 여러 줄이 동시에 완성되면 한 번에 지웁니다.
- 3개를 모두 쓰면 새로운 3개가 나옵니다.
- 남은 블록 중 어느 것도 놓을 수 없으면 게임 오버입니다.

### 점수

점수 공식은 `calculateScore` 함수 한 곳에만 있고, 점수를 더하는 곳도 `applyScore` 한 곳뿐입니다.

```
획득 점수 = 놓은 칸 수 + (지운 줄 수 × 10 + 다중 줄 보너스) × 콤보 배수 + 전부 제거 보너스
```

| 항목 | 값 |
| --- | --- |
| 블록 한 칸 | 1점 |
| 줄 하나 | 10점 |
| 다중 줄 보너스 | 2줄 +10, 3줄 +30, 4줄 +60, 5줄 +100, 6줄 +150 |
| 콤보 배수 | 연속 제거 횟수와 같음 (×1에서 시작, 최대 ×8) |
| 판 전부 제거 | +100 |

줄을 못 지운 배치는 2번까지 콤보를 유지하고, 3번째에 콤보가 끊깁니다. 점수판의 콤보 칸에 있는 막대 3개가 남은 기회입니다.
유예 없이 엄격하게 하려면 `game.js`의 `COMBO_GRACE`를 `0`으로 바꾸면 됩니다.

표시되는 효과: 2줄 `GREAT!`, 3줄 `EXCELLENT!`, 4줄 이상 `PERFECT!`, 판 전부 제거 `ALL CLEAR!`, 연속 제거 `COMBO ×n`.

### 블록

단일, 직선(2~5칸 가로·세로), 정사각형(2×2, 3×3), 직사각형, ㄱ·ㄴ자, L자, 반대 L자, T자, 지그재그, 큰 꺾임, 계단형을 합쳐 41종입니다.
회전 방향마다 별도 템플릿이며, 모양별 출현 확률은 `game.js`의 `SHAPE_TEMPLATES`에 있는 `weight` 값으로 조절합니다.

블록을 만들 때는 현재 판에 놓을 수 있는 모양 중에서 하나를 먼저 고르고, 나머지 둘은 일반 확률로 뽑습니다. 재시도 없이 후보 목록에서 뽑기 때문에 무한 루프가 생기지 않습니다.

## 저장되는 데이터

브라우저의 `localStorage`에만 저장합니다. 외부로 전송되는 데이터는 없습니다.

| 키 | 내용 |
| --- | --- |
| `blockpangpang.best` | 최고 점수 |
| `blockpangpang.sound` | 사운드 설정 (`on`/`off`). 진동도 이 설정을 따릅니다. |
| `blockpangpang.tutorialDone` | 튜토리얼을 봤는지 여부 |

## 폴더 구조

```
index.html          화면 구조
style.css           디자인과 애니메이션
game.js             1부 Core(순수 규칙), 2부 UI(입력, 렌더링, 효과, 사운드)
README.md
tests/
  rules.spec.js     규칙 테스트 본문 (Node와 브라우저 공용)
  run-tests.js      Node용 규칙 테스트 실행기
  index.html        브라우저용 규칙 테스트 페이지
  e2e.js            실제 브라우저를 터치·마우스로 조작하는 테스트
```

`game.js`의 Core는 기능별 함수로 나뉘어 있습니다.

| 기능 | 함수 |
| --- | --- |
| 배치 가능 검사 | `canPlace`, `canPlaceAnywhere` |
| 블록 고정 | `lockShape` |
| 완성 줄 탐지 | `findCompletedLines` |
| 줄 삭제 | `clearLines` |
| 점수 계산 | `calculateScore`, `applyScore` |
| 블록 생성 | `generateTray` |
| 게임 오버 판정 | `isGameOver` |

## 테스트 방법

**브라우저에서 규칙 확인**: `tests/index.html`을 열면 규칙 테스트 결과가 바로 표시됩니다. 설치가 필요 없습니다.

**Node로 규칙 확인** (Node 18 이상):

```bash
node tests/run-tests.js
```

**실제 브라우저로 터치·마우스 조작 확인** (Node 22 이상, Chrome 또는 Edge 필요):

```bash
node tests/e2e.js              # 결과만 출력
node tests/e2e.js screenshots  # screenshots 폴더에 화면도 저장
```

브라우저를 자동으로 찾지 못하면 환경변수 `CHROME_PATH`에 실행 파일 경로를 지정합니다.

## 지원 환경

Pointer Events를 지원하는 최신 브라우저(Chrome, Edge, Safari, Firefox, 삼성 인터넷)를 대상으로 합니다.
iPhone의 Safari는 진동 API를 지원하지 않아 진동 없이 동작합니다.
